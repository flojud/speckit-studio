# Security Policy

Speckit Studio is a personal open-source project that I maintain in my spare time. It runs locally on your machine and starts AI coding agents via the [Agent Client Protocol](https://agentclientprotocol.com) (ACP), so I take reports about process spawning, file access and permission handling seriously.

## Supported Versions

Only the latest release receives fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report security issues **privately** and not in a public issue, so there is time for a fix first.

Use GitHub's private reporting: open the [Security Advisories](https://github.com/flojud/speckit-studio/security/advisories/new) page of this repository and click **"Report a vulnerability"**. Only you and I can see the report.

Helpful to include:
- what the problem is and what an attacker could do with it,
- steps or a small proof of concept to reproduce it,
- your operating system and the Speckit Studio version.

## What to Expect

I'll answer as soon as I can, usually within a few days. Once I've confirmed the issue, I'll keep you posted on the fix, release it, and credit you in the advisory – unless you'd rather stay anonymous.
